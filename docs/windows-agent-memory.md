# Windows 11 Agent 命令行记忆

本项目在 Windows 11 上使用 PowerShell。执行命令前先确认 shell、解释器、工作目录和写入范围；遇到环境限制时先识别原因，避免把命令错误或沙箱行为误判为应用缺陷。

## PowerShell 参数和脚本

- 调用带空格的可执行文件路径，使用调用运算符：`& 'C:\Program Files\GitHub CLI\gh.exe' --version`。
- 不把 Bash heredoc、POSIX 路径语法或 `cmd.exe` 的转义规则直接放入 PowerShell。较长 Python 或 JavaScript 逻辑保存为脚本文件，再传递脚本路径。
- 用单引号表示不需要变量展开的文字；不要将用户文字拼接成 shell 命令。JSON 序列化不能代替 shell 转义。
- 不在双引号 PowerShell 字符串中直接嵌入反引号、`$()` 或未经处理的 `$`；这些字符可能改变命令含义。
- 多步依赖命令要检查 `$LASTEXITCODE`。不要用大量分隔标题、`echo` 或无条件串联掩盖失败。
- 使用任务专用变量名，不覆盖 `$HOME`、`$home` 或 `$CODEX_HOME`。

## 搜索和路径

- 先用 `rg --files` 或 `rg`。文件过滤用 `-g '*.py'`；不要把带 `*` 的 Windows 路径当作已经展开的文件名传入 `rg`。
- 读写具体文件用 `-LiteralPath`。访问脚本和资源前检查文件确实存在，避免连续读取猜测文件名。
- 删除或移动目录前，将目标解析为绝对路径并确认仍在指定目录内。不要将 PowerShell 枚举结果交给另一个 shell 执行删除。
- Windows 音频输出还需给临时 WAV 文件名留出路径长度预算。测试使用较短的私有 `--basetemp`，并保留路径预算断言；不要关闭安全检查来让测试通过。
- 测试边界目录逐段增长时，最后一段要按剩余预算截断，避免整段追加导致路径超过原定边界。

## 编码和文本正文

- 含中文的 Python 任务使用 UTF-8 模式，例如为该次启动设置 `PYTHONUTF8=1`；日志和证据文件明确按 UTF-8 写入。
- 多行 PR 正文保存到 UTF-8 文件，再使用 `gh pr create --body-file` 或 `gh pr edit --body-file`。保留真实换行，不把 JSON 中的 `\n` 当作 shell 中的换行。
- GitHub 的 `--match-head-commit` 使用完整提交 SHA；先读取实际 PR HEAD。分别查询每个仓库的真实默认分支，并核对 CI 分支过滤，不将一个仓库的 master/main 假定套用到另一个。
- 不为解决单次编码问题改动用户全局终端、代理或系统设置。

## 解释器和服务恢复

- TTSMore 后端使用 Python 3.11，前端包管理使用 pnpm。原生项目使用各自已有的解释器和依赖环境。
- `psutil.Process.exe()` 可能报告虚拟环境底层解释器。恢复服务时同时核对原命令行、工作目录和启动脚本所设置的环境变量。
- 某些便携启动脚本通过 `PYTHONPATH` 加载虚拟环境的包。缺少该变量时出现 `ModuleNotFoundError`，不等于项目真的没有安装依赖；先按原启动脚本复现环境。
- 后台 `Start-Process` 使用 `-WindowStyle Hidden`，除非用户要求可见窗口。不要为本项目测试关闭独立原生 TTS 应用。
- 停止自有后端后，进程及监听端口可能稍后才消失。重启前在有界期限内确认旧进程和监听退出，随后检查新后端 HTTP 就绪；遇到意外端口占用者不自动终止它。一次停止命令返回不能代替端口释放检查。

## 沙箱诊断

- CIM 无法访问、socket `WinError 10013`、`realpath` 的 `WinError 5`、pnpm `EPERM` 可能来自受限执行环境。保留错误和具体失败操作，按工具规则申请范围明确的升级后复核。
- 不用关闭防火墙、改代理、改 ACL 或修改产品逻辑来掩盖尚未确认的沙箱错误。
- `-ErrorAction SilentlyContinue` 会隐藏端口查询失败；需要判断服务是否运行时，使用可观察错误并结合真实 HTTP 响应。
- 默认临时目录可能很长。路径预算测试应使用短的工作区私有目录；已有目录不要直接覆盖清空，换一个新目录。
- 超时不是进程已经结束。确认测试或任务句柄的终态后再决定是否重试；只终止自己启动且已确认需要结束的测试命令。
- Windows asyncio 创建事件循环时也需要回环 socket。沙箱可使 `socketpair()` 卡在 `accept()`；使用测试的 `faulthandler_timeout` 定位，升级复核后清理已核实身份的自有测试进程，不修改产品的事件循环策略掩盖限制。

以上规则应随可复现错误更新，不保存用户名、机器路径、访问令牌、私有剧本或音频。
